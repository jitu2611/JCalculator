# JCalculator

A simple Android calculator learning project written in Java.

> **Archived learning project.** This repository uses an older Android project structure and is retained as an early mobile-development example.

## Interaction flow

```text
Number input → operation selection → expression state → calculated result
```

## Structure

- `JCalculator/src/.../MainActivity.java` — calculator UI and interaction logic
- `JCalculator/AndroidManifest.xml` — Android application manifest
- `JCalculator/build.gradle` — legacy Gradle build configuration

## Running

Open the `JCalculator/` directory in an Android Studio version compatible with the legacy Gradle/SDK configuration. Modern Android Studio versions may require a migration before building.

## Scope

This project demonstrates basic Android UI events and arithmetic state handling. It is not maintained as a production calculator application.
